# 💰 Personal Expense Tracker

A responsive **Personal Expense Tracker** web application built with HTML, Bootstrap, jQuery, and JavaScript. Track your daily expenses with ease! 🚀

## ✨ Features
- ➕ Add expenses with description, date, and amount
- 📊 View total expenses in real-time
- 💾 Data persistence using localStorage
- 🗑️ Delete expenses
- 📱 Fully responsive design

## 🛠️ Tech Stack
- 🌐 HTML5
- 🎨 CSS3
- 🅱️ Bootstrap 4.6.2
- 💛 jQuery 3.7.1
- ⚡ JavaScript (localStorage)

## 🚀 How to Run
1. Clone the repository
2. Open `index.html` in your browser
3. Start tracking your expenses!
